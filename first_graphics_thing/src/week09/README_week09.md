## Scene Features

- FPS-like movement with WASD (+ SPACE/CTRL)
- ambient + diffuse + specular lighting
- Blinn-Phong specular
- attenuation
- material struct
- diffuse maps
- specular maps
- optional textured / non-textured materials
- multiple point lights (toggle by pressing keys 1 and 2) (yellow light can be moved with I/J/K/L/U/O)
- normal debug shader (toggle with N)
- depth debug shader (toggle with V)
- first-person flashlight / spotlight ( toggle with F)
- transparent windows ( toggle with G )
- blurring effect ( toggle with B )
- skybox mode with directional light ( toggle with M )
- backpack to a glass texture ( toggle with H )
